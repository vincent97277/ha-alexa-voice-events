# Alexa Voice Events v0.3.1

This patch makes phrase setup simpler and adds a complete user guide.

- Enter phrases without leading Alexa. The Blueprint ignores one leading standalone
  `alexa` on either side after normalizing case and whitespace. Existing prefixed
  settings remain valid; original event text is preserved. Other punctuation,
  wake words, spelling and suffixes remain literal. Review equivalent phrases
  across different automations to avoid duplicate household actions.
- Reorganized English and Traditional Chinese README pages cover installation,
  setup, all six Blueprint fields, examples, recognition tips, updates and FAQ.
  Architecture and developer checks moved into linked documents.
- Each Blueprint field has a Help link to its exact v0.3.1 README section.
- Includes the maintainer-supplied transparent icon for README and HA's local
  `brand/icon.png` mechanism. The original 500px PNG is retained; the runtime
  icon is 256px with transparency. It is not a redesigned image.

## Install and update

Keep the component and Blueprint on v0.3.1. HACS updates the component, **not** an
already-imported Blueprint. Back up actual sources and consumer configurations,
replace the Blueprint at its original import path, validate and enable consumers
individually. No migration to new inputs is required from v0.3.0. For rollback,
restore the saved v0.3.0 files and complete automation settings.

## Validation and scope

Core 2026.10.2 / aioamazondevices 16.3.2 remains the supported combination;
no dependencies or Python runtime behavior were changed. Tests exercise the new
matching through the real HA automation engine and preserve existing freshness,
reception, session, routing and reply coverage. Type, formatting, documentation,
image packaging and exact-commit main/tag CI are checked before formal release.

The prior audio issue was confirmed resolved and closed by the user; this patch
does not reopen it or claim a new audio fix. No new live HA/HACS icon or Help-click
acceptance, physical speech tests or other-speaker validation is claimed.
`never mind` is an optional experiment, not a guaranteed way to suppress native
interaction; Stop remains best effort and may stop music. A service return still
is not a playback receipt, and already-submitted commands cannot be recalled.

Downloads use GitHub's automatic source ZIP/tarball; there are no custom assets.
